# 📝 Sticky Task - Aesthetic Task Manager

Aplikasi web pencatat tugas (to-do list) interaktif berbentuk *sticky notes* yang aesthetic dan modern. Dibuat untuk membantu mengelola tugas harian agar lebih terstruktur, rapi, dan menyenangkan!

## ✨ Fitur Utama
- 📌 **Sticky Notes Interaktif**: Tampilan catatan tempel dengan warna pastel yang lucu dan efek *hover* yang halus.
- ✅ **Checklist Terstruktur**: Centang tugas yang sudah selesai dengan animasi *strikethrough* (teks tercoret).
- 📊 **Progress Indicator**: Pantau kemajuan tugas lo (misal: "2/4 done").
- 🔍 **Pencarian Cepat**: Cari catatan dengan mudah lewat *search bar*.
- 💾 **Penyimpanan Lokal (LocalStorage)**: Data tugas lo gak bakal hilang meskipun browser ditutup atau laptop dimatikan.
- 📱 **Fully Responsive**: Tampilan optimal di HP, tablet, maupun laptop.

## 🛠️ Teknologi yang Digunakan
- **Frontend**: React.js + Vite
- **Styling**: Tailwind CSS / Custom CSS
- **Desain**: Arena AI (Aesthetic Pastel Scrapbook Style)
- **Font**: Poppins / Nunito / Inter
